A fast drop-in CSV reader for Node 22 that survives broken CSV files: ragged rows, stray quotes, embedded newlines and BOMs. `solve.js` exports the same interface as the baseline reader but parses roughly 2x faster on the practice corpus; `main.ts` is the grader entrypoint.

## Run it

```sh
node --experimental-strip-types main.ts
```
